# TEMU — Event Discovery & Ticketing Platform

**Ada event, ada cerita.**

TEMU is a web-based event discovery and ticketing platform that helps users explore events, book tickets, and create memorable experiences.

From concerts and festivals to workshops, seminars, and community gatherings, TEMU brings different events together in one platform.

## Features

- **Event Discovery** — Explore and search events by category, location, and date.
- **Ticket Booking** — Browse ticket options and book tickets easily.
- **Digital Tickets** — Get digital tickets with unique QR codes.
- **User Authentication** — Secure registration and login.
- **Organizer Dashboard** — Manage events, ticket sales, and bookings.
- **QR Check-in** — Validate tickets and manage event attendance.

## Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, bcrypt
- **Payment:** Payment Gateway Integration
- **Other Tools:** Git, Cloudinary
